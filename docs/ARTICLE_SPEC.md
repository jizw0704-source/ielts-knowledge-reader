# ARTICLE_SPEC.md｜IELTS-style 文章规范

## 1. 文章定位

IELTS Knowledge Reader 的内置文章不是 IELTS / Cambridge IELTS 真题原文，而是原创 IELTS-style 英文知识阅读文章。

文章目标：

- 接近 IELTS Academic Reading 的文本长度和信息密度；
- 同时帮助用户提升阅读能力，并积累可复述、可迁移的背景知识；
- 避免使用真实 IELTS / Cambridge IELTS 原文；
- 适合手机端精读和点词学习。

核心主张：**Read for IELTS. Learn for life.**

每篇正式文章都必须通过两道门槛：

- **阅读训练门槛**：文本能够训练信息定位、篇章理解、逻辑关系、学术词汇和长难句处理能力；
- **知识价值门槛**：文章回答一个清晰的知识问题，并让用户读后获得若干可以准确复述的关键认识。

## 2. 长度标准

每篇文章目标长度：

- 标准范围：750–900 words；
- 最低可接受：700 words；
- 不建议超过：950 words；
- 三篇文章合计：约 2250–2700 words。

当前原则：

- 后续新增文章或重写文章，应尽量满足 750–900 words；
- 不再新增 300 words 以下的短文章作为正式阅读文章；
- 短文只能作为 demo 或 teaser，不作为正式文章库内容。

## 3. 风格标准

文章应接近 IELTS Academic Reading 长文风格：

- 信息密度较高；
- 段落结构清晰；
- 包含定义、解释、因果、对比、举例、限制条件；
- 避免过度口语化；
- 避免过度简单的科普短文；
- 不写成考试题，不附真实 IELTS 题目。

## 4. 难度标准

建议难度：

- IELTS 6.5–7.5；
- 句子长度适中；
- 包含一定学术词汇；
- 保留少量长难句；
- 不堆砌生僻词。

## 5. 知识价值标准

每篇文章在动笔前必须明确一个“核心知识问题”，例如某种现象为什么发生、一个系统如何运作、一个观念如何演变，或不同解决路径有什么取舍。

正文应做到：

- 至少解释一个关键概念、机制、因果链或历史演变；
- 使用具体但可核查的事实支撑，不用空泛口号代替知识；
- 区分已知事实、合理解释、争议和限制条件；
- 读完后，用户应能用自己的话复述 2–4 个关键知识点；
- 避免“考试填充文”、百科条目堆砌和没有中心问题的泛泛科普；
- 在连续内容排期中保持学科与主题多样性，避免长期集中于单一领域。

## 6. 每篇文章数据结构要求

每篇文章应包含：

- id
- title
- sourceType
- difficulty
- tags
- summaryZh
- summaryEn
- content
- optional: sourceNote
- optional: relatedTopics

### references 字段

`references` 是后续新文章的推荐字段。旧文章可以缺省，不强制回填。

新文章应优先包含 `references`，用于记录参考来源：

```js
references: [
  {
    title: '',
    source: '',
    url: '',
    usage: ''
  }
]
```

- 不允许伪造来源；
- 不允许为了补全字段而给旧文章添加不真实来源；
- `references` 只说明参考来源，不代表文章转载、翻译或改写；
- 具体内容流程应遵守 `docs/CONTENT_PIPELINE.md`。

## 7. 版权边界

禁止：

- 使用真实 IELTS / Cambridge IELTS 原文；
- 使用扫描版、OCR 版、盗版真题；
- 以平台内容形式售卖未经授权的真题原文；
- 将真实真题轻微改写后作为原创内容。

允许：

- 原创 IELTS-style 文章；
- 使用公开事实和通用知识重新组织原创表达；
- 用户自有材料导入后由用户自己使用；
- 记录来源信息和用户自有材料说明。

## 8. 后续扩写计划

当前三篇文章后续应逐篇扩写：

1. How Cities Adapt to Extreme Heat
2. The Hidden Intelligence of Plants
3. The History of Timekeeping

扩写顺序建议：

- 先扩写一篇；
- 验收文章长度、可读性、手机端显示；
- 再扩写下一篇；
- 每篇扩写后重新跑词典覆盖检查。

## 9. 验收标准

每篇正式文章验收应包括：

- 文章长度是否在 750–900 words；
- 是否原创；
- 是否保持 IELTS-style；
- 是否回答了一个清晰的核心知识问题；
- 是否提供 2–4 个可准确复述的知识点；
- 是否区分事实、解释和限制条件，且没有虚构数据或来源；
- 是否适合手机阅读；
- 单词数统计是否正常；
- 建议阅读时长是否正常；
- 点词释义是否基本可用；
- 生词本和读后感是否仍正常。
